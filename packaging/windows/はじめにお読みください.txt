  Orbit（オービット）　はじめにお読みください
════════════════════════════════════════════════════════

Orbit は、手持ちの服を写真で登録しておくと、
その日の組み合わせを AI が選んでくれるアプリです。
選んでもらったコーデは、あなたの全身写真に着せた画像にして残せます。

インターネット上のサービスではなく、あなたのパソコンの中だけで動きます。
写真も記録も、あなたのパソコンから外へ出ることはありません。
（AI に選んでもらうときだけ、その一回分の写真が Google の AI に送られます）

このファイルは、最初の一回だけ読んでいただければ大丈夫です。
あとから読み返したくなったら、Orbit のフォルダーの中に入っています。


────────────────────────────────────────────────────────
1. 起動のしかた
────────────────────────────────────────────────────────

【手順1】まず、ZIP ファイルを「展開」します

  受け取った ZIP ファイルを右クリックして、
  「すべて展開」を選んでください。

  ※ ここが大事です。
    ZIP ファイルをダブルクリックすると中身が見えるので、
    そのまま起動したくなりますが、それではうまく動きません。
    見えているだけで、まだ本当には取り出されていないためです。
    かならず「すべて展開」をしてから使ってください。

  展開する場所は、「ドキュメント」や「デスクトップ」がおすすめです。
  「Program Files」に置くと、パソコンの管理者パスワードを
  求められることがあります。


【手順2】Orbit.exe をダブルクリックします

  展開してできた「Orbit」フォルダーを開くと、
  中に「Orbit」という名前のファイル（紺色と金色の丸いアイコン）があります。
  これをダブルクリックしてください。

  ※ ファイル名が「Orbit.exe」と表示されることもあります。同じものです。


【手順3】少し待ちます

  はじめての起動は 30 秒ほどかかることがあります。
  内側で最初の準備をしているためで、二回目からは早くなります。

  準備ができると、ふだんお使いのブラウザー（Edge、Chrome など）が
  自動的に開いて、Orbit の画面が出ます。


【毎回かんたんに開けるようにする】

  「Orbit」ファイルを右クリック →「送る」→
  「デスクトップ (ショートカットを作成)」

  Windows 11 では、右クリックしたあと
  「その他のオプションを表示」を押すと「送る」が出てきます。

  これでデスクトップにアイコンができ、次からはそれを
  ダブルクリックするだけになります。

  ※ フォルダーごと移動しても大丈夫ですが、
    「Orbit」ファイルだけを取り出して別の場所に置くと動きません。
    フォルダーの中身が一式そろって、はじめて動くためです。


────────────────────────────────────────────────────────
2. 初回だけ出る警告について（いちばん大事です）
────────────────────────────────────────────────────────

はじめて起動するとき、青い画面でこのような警告が出ます。

  ┌──────────────────────────────────────────┐
  │  Windows によって PC が保護されました       │
  │                                          │
  │  Microsoft Defender SmartScreen は認識さ   │
  │  れないアプリの起動を停止しました。       │
  │                                          │
  │                          [ 実行しない ]   │
  └──────────────────────────────────────────┘

これは故障でもウイルスでもありません。

Windows は「世界中でたくさんの人が使っている有名なアプリかどうか」を
見ています。Orbit はあなたのために作られたアプリで、
世の中に出回っていないので「知らないアプリだ」と言われているだけです。


【この画面を通る方法】

  (1) 文章の中ほどにある「詳細情報」という小さな青い文字を
      クリックします。

  (2) すると、画面の下に「実行」というボタンが新しく出てきます。
      それを押してください。

  ┌──────────────────────────────────────────┐
  │  Windows によって PC が保護されました       │
  │                                          │
  │  詳細情報          ←ここをクリック         │
  │                                          │
  │  アプリ: Orbit                            │
  │                                          │
  │            [ 実行 ]      [ 実行しない ]   │
  │              ↑これを押す                  │
  └──────────────────────────────────────────┘

  ※「実行しない」しか見えないときは、まだ「詳細情報」を
    押していない状態です。先に「詳細情報」を押してください。

この警告が出るのは最初の一回だけです。
二回目からは、そのまま起動します。


────────────────────────────────────────────────────────
3. AI の機能を使うには（最初に一回だけ）
────────────────────────────────────────────────────────

Orbit で AI を使う部分（写真の読み取り・コーデの提案・試着画像）は、
Google の AI を借りて動いています。

そのため、「あなたが Google の AI を使いますよ」という合図になる
文字列を、最初に一度だけ登録していただく必要があります。
これを「API キー」と呼びます。
パスワードのような、英数字の長い文字列だと思ってください。

  ・無料で発行できます（クレジットカードの登録は要りません）
  ・一日に使える回数の上限がありますが、
    ふだん使う分にはまず届きません
  ・登録は最初の一回だけです


【登録のしかた】

  (1) Orbit の画面のいちばん下にある「その他」を押します。

  (2)「AI連携」という欄の中の
     「Google AI Studio を開く」ボタンを押します。
      ブラウザーで Google のページが開きます。

  (3) お持ちの Google アカウントでログインします。

  (4)「Create API key」というボタンを押します。
      （日本語表示なら「API キーを作成」です）

  (5) 「AIza」ではじまる長い文字列が出てきます。
      それをコピーします。
      コピーのボタンが横に付いていることが多いです。

  (6) Orbit の画面に戻って、「発行したキーを貼り付け」の欄に
      貼り付け（Ctrl + V）、「連携する」を押します。

  「連携済み」と表示されたら完了です。

  ※ このキーは、あなたのパソコンの中に保存されます。
    次から入力する必要はありません。

  ※ キーを登録しなくても、服を登録したり見返したりする機能は
    そのまま使えます。AI の部分だけがお休みになります。


────────────────────────────────────────────────────────
4. 使い方
────────────────────────────────────────────────────────

  ① 服を登録する

    画面の下の「服を追加」を押します。

    お手持ちの服の写真を選ぶと、AI が写真を見て
    名前・カテゴリー・色・種類・素材・シルエット・季節を
    自動で入れてくれます。

    自動で入った内容が違っていたら、その場で直せます。
    直した内容のほうが優先されるので、遠慮なく書き換えてください。
    ここが正確なほど、あとの提案がしっくりくるようになります。

    ・服だけが大きく写るように撮ると、より正確に読み取れます
    ・写真なしで、名前だけ手で入力して登録することもできます

    まずはトップス（上）とボトムス（下）を
    何着かずつ登録してみてください。
    組み合わせを選ぶには、上と下が最低ひとつずつ必要です。


  ② 全身写真を登録する　← これがないと「試着」ができません

    画面の下の「その他」→「全身写真」から登録します。

    全身が写っていて、明るい場所で撮った写真がいちばんきれいに
    仕上がります。まっすぐ立っている写真がおすすめです。

    この写真は、③で選んでもらったコーデを「着せてみる」ときの
    土台になります。登録は一枚だけ、いつでも差し替えられます。


  ③ 今日のシーンを一言だけ書く（書かなくても大丈夫です）

    ホーム画面の「今日のシーン」に、
    「出勤」「デート」「雨で肌寒い」のように短く書けます。

    「出勤」「デート」「友達と」などのボタンも用意してあるので、
    押すだけでも大丈夫です。

    空のままでも、いつも通り選んでくれます。
    書いておくと、その日の予定に寄せて選んでくれます。


  ④ AI に選んでもらう

    ホーム画面の「AIに選んでもらう」を押します。

    クローゼットに登録された服の中から、その日の一着分の
    組み合わせを選んで、選んだ理由も一緒に見せてくれます。

    気に入らなければ、もう一度押せば別の組み合わせを選びます。


  ⑤ 試着した姿を作る

    選んでもらったコーデの画面を下にスクロールすると、
    「試着する」というボタンがあります。

    これを押すと、②で登録した全身写真に、そのコーデを着せた
    画像を AI が作ります。できあがるまで少し時間がかかります。

    気に入らなければ「作り直す」で作り直せます。


  ⑥ 記録に残る

    選んでもらったコーデは、そのまま記録として残ります。
    画面の下の「記録」から、いつでも見返せます。

    ひとつひとつに「LOOK 001」のような番号と日付が付きます。
    お気に入りの印を付けたり、いらない記録を消したりもできます。

    「クローゼット」からは、登録した服の一覧が見られます。
    服をひとつ選ぶと、その服を使ったコーデも一緒に出てきます。


────────────────────────────────────────────────────────
5. 終了のしかた
────────────────────────────────────────────────────────

  ※ ブラウザーのタブや窓を閉じただけでは、Orbit は終了しません。

  画面が消えるので終わったように見えますが、Orbit 本体は
  パソコンの中で動いたままになっています。
  次のようにして、きちんと終了してください。


【終了する手順】

  (1) 画面右下、時計のとなりを見てください。
      小さなアイコンが並んでいるところです。
      Orbit のアイコン（紺色と金色の丸）があります。

      見あたらないときは、そのあたりにある
      「∧」（上向きの山かっこ）を押すと、隠れているアイコンが出てきます。

  (2) Orbit のアイコンを右クリックします。

  (3) 出てきたメニューの「終了 (Orbit を閉じる)」を選びます。

  これで完全に終了します。


【ついでに】

  ・このアイコンを左クリックすると、Orbit の画面をもう一度開けます。
    ブラウザーのタブを間違って閉じてしまったときに便利です。

  ・パソコンをシャットダウンすれば、当然ですが一緒に終了します。
    終了し忘れても、何かが壊れることはありません。

  ・Orbit を起動したままパソコンを使い続けても問題ありませんが、
    使わないときは終了しておくと、パソコンが少し軽くなります。


────────────────────────────────────────────────────────
6. 写真とデータの保存場所
────────────────────────────────────────────────────────

登録した服の写真・全身写真・コーデの記録・AI のキーは、
すべて次の場所にまとめて保存されています。

  %LOCALAPPDATA%\Orbit


【開き方】

  エクスプローラー（フォルダーの窓）を開いて、
  上のアドレス欄に上の一行をそのまま貼り付けて Enter を押します。


【知っておいていただきたいこと】

  ・このデータは、Orbit のフォルダーとは別の場所にあります。
    ですから Orbit のフォルダーを消したり、別の場所へ移したりしても、
    登録した服や記録は消えません。

  ・新しい Orbit を受け取って入れ替えるときも、
    古いフォルダーを消して新しいものを置くだけで、
    中身はそのまま引き継がれます。

  ・バックアップを取りたいときは、この「Orbit」フォルダーを
    まるごとコピーして、USB メモリなどに保存してください。
    元に戻したいときは、同じ場所に戻すだけです。

  ・逆に、記録をぜんぶ消してやり直したいときは、
    Orbit を終了してから、このフォルダーを削除してください。
    次に起動すると、まっさらな状態から始まります。
    （元には戻せませんので、消す前にコピーを取っておくと安心です）


────────────────────────────────────────────────────────
7. 困ったときは
────────────────────────────────────────────────────────

■ ダブルクリックしても何も起きない

  ・まず 30 秒ほど待ってみてください。
    はじめての起動は準備に時間がかかります。

  ・青い警告画面が出ていませんか。
    このファイルの「2. 初回だけ出る警告について」をご覧ください。

  ・ZIP のまま実行していませんか。
    「1. 起動のしかた」の【手順1】をご覧ください。

  ・すでに Orbit が起動していると、二重には起動しません。
    画面右下のアイコンを探してみてください。


■ ブラウザーが自動で開かない／画面を閉じてしまった

  画面右下（時計のとなり）の Orbit のアイコンを左クリックすると、
  もう一度開きます。

  それでも開かないときは、ブラウザーのアドレス欄に
  次の住所を入れてみてください。

      http://127.0.0.1:8080

  ※ ほかのアプリがこの番号を使っていると、Orbit は自動で
    別の番号に移ります。そのときは上の住所では開きません。
    アイコンにマウスの矢印を乗せて少し待つと、
    いま使っている住所が表示されますので、それを使ってください。


■ AI の機能が使えない・エラーが出る

  ・「その他」→「AI連携」が「連携済み」になっていますか。
    なっていなければ、このファイルの「3.」をご覧ください。

  ・インターネットにつながっていますか。
    AI の部分だけはインターネットを使います。

  ・一日に使える回数の上限に届いた可能性があります。
    その場合は、日付が変わるとまた使えるようになります。

  ・少し時間をおいて、もう一度お試しください。
    混みあっていて応答が返らないこともあります。


■「試着には全身写真が必要です」と出る

  「その他」→「全身写真」から、全身が写った写真を
  登録してください。登録が済むと、そのまま試着に戻れます。


■ 服の写真が表示されない

  「6. 写真とデータの保存場所」のフォルダーを、
  移動したり消したりしていないかご確認ください。
  写真の実体はそこに保存されています。


■ それでも解決しないとき

  次のファイルに、Orbit が動いたときの記録が残っています。

      %LOCALAPPDATA%\Orbit\logs\orbit.log

  このファイルを送っていただければ、原因を調べられます。
  写真やキーの中身は入っていませんので、そのままお送りいただいて
  大丈夫です。


────────────────────────────────────────────────────────

  たくさん登録するほど、提案は楽しくなります。
  まずは何着か入れてみてください。
